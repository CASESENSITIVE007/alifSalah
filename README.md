# Alif-Salah — Muslim Prayer & Community App (Phase 1)

*Your Masjid, in your pocket.* Bridges local Masjids and their communities with
live, Imam-managed Jamaat timings.

## Features (Phase 1)

| Feature | Details |
|---|---|
| **Community Spaces** | Imams create their Masjid's space; residents search & join. |
| **Live Jamaat timings** | Imam publishes Adhaan & Jamaat times; members' dashboards update in real time. |
| **Nearby Masjids** | See Jamaat timings of *all* Masjids around your current location — **no enrollment needed**. Perfect when travelling to another city. |
| **Adhaan buzzer** | Local notifications at Adhaan time + 10 min before Jamaat — **only for Masjids you have joined**. |
| **Qibla compass** | Magnetometer + GPS great-circle bearing to the Kaaba. |
| **Fundraising** | Imams post campaigns with the Masjid's payment QR code; users scan with any payment app. Payments never touch the app. |
| **One-way broadcast** | Imam announcements only. No chats, zero noise. |

## Tech stack

- **Flutter** (Android / iOS / web) — UI
- **Firebase** — Auth (phone OTP), Cloud Firestore (data + realtime), FCM-ready
- **Geohashing** — nearby-Masjid radius queries ([lib/utils/geo.dart](lib/utils/geo.dart))
- **flutter_local_notifications** — Adhaan buzzer scheduling

## Setup

1. **Flutter SDK** — installed at `C:\Users\moham\flutter` (added to PATH).
2. **Firebase project** (one-time):
   ```
   npm install -g firebase-tools
   firebase login
   dart pub global activate flutterfire_cli
   flutterfire configure
   ```
   Select/create your Firebase project, pick Android (+ others). This rewrites
   `lib/firebase_options.dart` with real keys.
3. In the [Firebase console](https://console.firebase.google.com):
   - **Authentication → Sign-in method → Phone**: enable.
   - **Firestore Database**: create, then paste `firestore.rules` into Rules.
4. Run:
   ```
   flutter pub get
   flutter run
   ```

## Verifying an Imam's Masjid

New Masjid spaces are created with `verified: false`. After manually verifying
the Imam, open the Masjid document in the Firestore console and set
`verified: true`.
